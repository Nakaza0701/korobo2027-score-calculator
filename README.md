# korobo2027-score-calculator

交流ロボコン2027の得点計算ツールです。
シミュレーションやチームの練習にぜひ役立ててください。

## 公開ページ

[交流ロボコン2027 得点計算ツール](https://nakaza0701.github.io/korobo2027-score-calculator/)

## 使い方

チームカラーを選択 → バケツ・ボールを記録 → 得点計算 という流れです。

1. チーム設定から、自チームのチームカラーを設定します。
   タッグメイトのチームカラーは自動で設定されます。

2. 得点を追加するときは、
   まず「バケツを追加」を押して、バケツの色（交換の有無）と設置場所を選択します。
   自チームのバケツなら自チームのチームカラーを、
   タッグメイトからもらったバケツならタッグメイトのチームカラーを選択してください。

3. バケツ内に入っているボールを追加するときは、
   追加したいバケツの中にある「ボールを追加」を押して、
   ボールの色（交換の有無）を選択します。

4. バケツを削除するときは、「バケツを削除」を押します。
   ただし、そのバケツに入っていたボールも同時に削除されます。
   ボールを1つずつ削除したいときは、「ボールを削除」を押します。

5. 得点は自動で計算され、画面の下の方で値が変わるたびに更新されます。

6. 「入力内容をリセット」を押すことで、オブジェクトをすべて削除できます。

## 得点

交流ロボコン2027ルールブックを参考にさせていただきました。

- 山に置かれたオブジェクトが、得点になる。

- 得点は、次の式で計算する。
  得点＝（オブジェクトの点数×場所の倍率×交換倍率）の総和

- 得点は、タッグ2台の合計とする。

### a) オブジェクトの点数

- バケツ 1点
- ボール 2点
  ※ボールは、バケツの中に入っているものだけが得点になる。

### b) 場所の倍率

- 山頂 ×4
- 山小屋 ×2
- 登山口 ×1

### c) 交換倍率

- オブジェクト交換ゾーンでタッグメイトと交換したオブジェクトは、×5
- それ以外のオブジェクトは、×1
  ※交換倍率は、オブジェクト1個ごとに判定する。交換倍率は重ねてかからず、×5までとする。往復して元の色に戻ったオブジェクトは、交換していない扱いとする。
  ※交換したオブジェクトは、色で判定する。タッグメイトの色のオブジェクトを自チームのエリア側の山に置いたものが、交換したオブジェクトとなる。
